# 출시 체크리스트 (1.4.0)

1.4.0 배포 전에 처리할 일. 데스크톱만 업데이트.

## 1. AI로 매물 등록
- [ ] 이미지 텍스트 인식(OCR)으로 매물 등록 — Claude 이미지 입력으로 글자 인식 가능하므로 별도 OCR 없이 시작, 정확도가 부족하면 CLOVA OCR 검토
- [ ] 녹음 파일 분석으로 매물 등록 — 데스크톱은 파일 선택·끌어다 놓기로 입력, STT는 CLOVA Speech
  - 확인 필요: 데스크톱 앱 안 마이크 녹음도 넣을지
- [ ] 공통 흐름: 추출(Claude structured outputs) → 확인 화면(`EditPropertyVM`에 새 매물 초안 모드 추가) → 저장
  - 추출한 주소는 `AddressUseCase`(도로명주소 검색 + Geocode)로 후보를 고르게 함
  - 대화·이미지에 없는 집주인 전화번호는 빈 칸으로 두고 필수 입력
  - 녹음 파일은 분석 직후 삭제

## 2. 블로그 글 AI 작성
- [ ] 매물 상세 정보 + 사진(Claude 이미지 입력, 전송 전 리사이즈)으로 장점을 뽑아 글 생성
  - 네이버 블로그 글쓰기 API 종료로 자동 업로드 불가 → 본문 텍스트 복사 + 사진 폴더 열기 (HTML·사진 동시 복사는 PoC 후 결정)
- [ ] 1.2.0에서 주석 처리한 AI 글쓰기 진입점 다시 열기 (프록시 적용 후)
- [ ] 사진 복사 시 HEIC 원본 확인 필요: 모바일 `Pasteboard.writeImage`에 HEIC bytes를 넣으면 붙여 넣는 앱이 못 읽을 수 있음 → 확인 후 필요하면 PNG로 변환 (`blog_repository_impl.dart`의 `_resizeToPng` 참고)
- [ ] Windows: `windows/runner/flutter_window.cpp`의 HTML 클립보드 채널 빌드(`/W4 /WX`) 확인, 본문 붙여넣기 시 네이버·노션 서식 적용 확인, 사진 복사(`Pasteboard.writeFiles`) 확인
- [ ] Android: 사진 복사(`Pasteboard.writeImage` + `FileProvider` 설정)와 이메일 문의(`mailto` queries) 실기기 동작 확인

## 3. API 키 처리 (서버리스 프록시 + 초대 코드)

- [ ] 사람별 초대 코드를 앱 설정에 입력해야 AI 기능이 보임 (코드 없는 사용자에게는 숨김), 사람별로 끊을 수 있음
