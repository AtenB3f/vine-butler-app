# 출시 체크리스트 (2.2.0)

2.2.0 배포 전에 처리할 일. 1.4.0 AI 기능 모바일 적용.

## 1. 녹음 입력
- [ ] 앱 안 녹음: 매물 등록 화면 버튼으로 마이크 녹음 (대면 상담·스피커폰 통화용, 통화 회선 음성 직접 녹음은 OS가 막음)
- [ ] 통화 녹음 파일 공유 받기: Android `SEND` + `audio/*` intent-filter → iOS Share Extension(Swift 타깃 + App Group)
- [ ] 마이크 권한(iOS `NSMicrophoneUsageDescription`, Android `RECORD_AUDIO`)
- [ ] 녹음 화면에 녹음 적법성 안내 문구 (본인이 참여하지 않은 대화 녹음은 불법)

## 2. 블로그 글 AI 작성
- [ ] 요청 흐름: 앱 → 앱 서버(로그인·사용량 확인) → 서버가 CLOVA 호출 후 결과 저장 → 앱에 결과 전달
  - 앱은 외부 AI API를 직접 호출하지 않음 (API 키는 서버에만)
  - 생성 중 앱이 백그라운드로 가거나 종료돼도 서버에서 생성이 이어지고, 앱은 다시 열릴 때 결과를 받음
  - 응답 시간 실측(포그라운드, CLOVA 직접 호출): macOS 18.5초, iOS 21.0초 → 사진 5장·토큰 조정 후에도 1분 이내 예상
- [ ] 확인 필요: 결과 전달 방식 (앱이 조회 / 푸시 알림)
