# 출시 체크리스트 (2.1.0)

2.1.0 배포 전에 처리할 일.

## 동기화 설계 (1.0.0부터 저장 중인 필드)
- 기본키는 앱에서 생성한 UUID(`id`)
- `updatedAt`: 마지막 수정 시각
- `deletedAt`: 소프트 삭제 (삭제 시 행을 지우지 않고 표시)
- `syncedAt`: nullable, 마지막으로 동기화된 시점의 `updatedAt` 값. `syncedAt == null || updatedAt > syncedAt`이면 동기화 필요

## 1. 로컬 데이터 동기화
- [ ] 동기화 필요한 매물을 UUID 기준 upsert로 일괄 업로드(재시도 안전) → 성공 시 업로드한 시점의 `updatedAt` 값을 `syncedAt`에 기록
- [ ] 이후 `updatedSince` 기준으로 서버 변경분(크롤링 데이터 포함)을 받아 로컬에 반영
- [ ] 충돌 처리는 1차에서 마지막 수정(`updatedAt`) 우선
