# 출시 체크리스트 (1.2.0)

1.2.0 배포 전에 처리할 일.

## 1. iOS / App Store
- [x] iOS `Info.plist`에 `NSLocationAlwaysAndWhenInUseUsageDescription` 추가 (문구는 `NSLocationWhenInUseUsageDescription`과 동일하게: "현재 위치를 기반으로 지도를 표시하기 위해 사용합니다.")
  - 이유: App Store 업로드 시 ITMS-90683 (Missing purpose string). `geolocator_apple` 2.4.3이 `requestAlwaysAuthorization`을 참조해 앱이 항상 허용을 요청하지 않아도 키가 필요함
  - 대안: 빌드 설정 `BYPASS_PERMISSION_LOCATION_ALWAYS=1`로 해당 API를 빼는 방법도 있으나, 네이버 지도 SDK 참조 여부를 확인하지 않아 키 추가가 더 안전
  - 빌드번호는 스토어에 올라간 번호보다 크게
