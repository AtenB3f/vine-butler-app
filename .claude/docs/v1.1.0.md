## 0. 공통
- [x] `pubspec.yaml` 버전 1.1.0으로 올리기 (빌드번호는 스토어 업로드마다 증가)
- [x] 개인정보처리방침 수정 (기존 시행 2026/10/22 기준)
  - 2. 기기 내 저장 정보: "면적" 삭제 (매물 모델에 면적 필드 없음)
  - 3. 접근 권한: 위치(선택) 추가 — 지도에서 내 위치 표시, 가까운 매물 먼저 보여주기용. 거부해도 지도와 그 외 기능 사용 가능. 기기 설정에서 언제든 변경 가능
  - 위치정보 항목 신설: 권한 허용 시에만 현재 위치 확인, 기기 안에서 지도 이동·거리 계산에만 사용, 기기 저장·개발자 서버 전송 없음
  - 4. 외부 서비스 이용: 네이버 지도 SDK 행을 "지도 화면 영역의 지도 데이터 요청(현재 위치 주변 포함) / 매물 위치 및 내 위치 주변 지도 표시"로 구체화
  - 5. 제3자 제공 및 처리 위탁: "4항의 외부 서비스 이용 외에는" 단서 추가
  - 9. 방침의 변경: 시행일을 1.1.0 배포일로 갱신, 이전 방침(2026/10/22)은 지우지 않고 링크로 보존
  - 권장: 8. 문의에 개인정보 보호책임자 이름 명시
- [x] 확인 필요: 위치정보법상 위치기반서비스사업자 신고 대상인지 (위치를 기기 안에서만 쓰고 저장·전송하지 않는 경우)
